Where each licence text in this directory came from
===================================================

docs/LICENSING.md §4 says these are "taken from spdx.org/licenses or
gnu.org, never from a blog or a paste". This file is the evidence for that
claim: the exact URL each file was fetched from and its SHA-256, so a
reviewer can re-fetch and diff rather than read 35 KB of GPL by eye.

Where a licence has a canonical publisher — the FSF for the GNU licences,
the ASF for Apache-2.0, Mozilla for the MPL, the OFL project for OFL-1.1 —
the publisher's own plain-text file is used in preference to SPDX's
re-typeset copy. SPDX reflows its texts to ~110 columns; the publishers'
are the documents the licences themselves refer to.

Two of these are not standalone licences and are shipped because an SPDX
expression in the closure names them:

  LGPL-3.0.txt      is the *additional permissions* document. LGPLv3 sits on
                    top of GPLv3, so every LGPL row also carries GPL-3.0.txt
                    and the two must be read together.
  LLVM-exception.txt is an exception to Apache-2.0, not a licence; the rows
                    that name it carry Apache-2.0.txt beside it.

MIT.txt, ISC.txt, BSD-2-Clause.txt, BSD-3-Clause.txt and Zlib.txt are the
*templates*, with `<year>` and `<copyright holders>` unfilled — that is what
the canonical text is. The filled-in copyright line for each component is
the `copyright` field of its row in components.json, taken from that
component's own licence file, and the screen prints it above the text.
